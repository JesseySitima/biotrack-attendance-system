# BioTrack Attendance System

## Overview

BioTrack is a biometric attendance management system
that allows organizations to track employee attendance
using fingerprint authentication.

## Technology Stack

Backend:
- FastAPI
- PostgreSQL

Frontend:
- React
- TypeScript

Hardware:
- ESP32
- Fingerprint Sensor

## Main Users

- Administrator
- HR Officer
- Manager
- Employee

## Main Features

- Employee management
- Fingerprint attendance
- Reports
- Dashboard analytics
